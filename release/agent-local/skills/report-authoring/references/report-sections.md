# 报告章节模板

## 通用经营分析

1. 摘要：本期最重要的 3 个结论，每个结论带 1 个关键数字。
2. 核心 KPI：收入/单量/成本/效率等，展示本期、上期、变化率。
3. 趋势：按日/周/月展示主指标，标注目标线或异常点。
4. 结构：按组织、渠道、品类、客户等维度拆解贡献。
5. 异常与归因：异常点、影响金额/数量、下钻维度、可能原因。
6. 数据质量：缺失项、口径待确认项、异常值处理方式。
7. 建议：每条建议对应一个结论，写清责任方向和验证指标。

## 库存分析报告

1. 摘要：库存总量/金额变化、周转变化、主要风险。
2. KPI：库存量、库存金额、周转天数、呆滞金额、库位利用率。
3. 趋势：库存量与金额走势，对比出库量。
4. 结构：按仓库/品类/库龄/ABC 拆解。
5. 风险：呆滞、临期、负库存、账实差异。
6. 质量：快照时点、状态口径、缺失维度。
7. 建议：补货、清滞、调仓、盘点。

## 入库履约报告

1. 摘要：收货量、及时率、差异率。
2. KPI：收货及时率、上架及时率、收货差异率、入库周期。
3. 趋势：按日/周看及时率与到货量。
4. 结构：按供应商、仓库、单据类型拆解。
5. 异常：延迟单据、差异类型、越库情况。
6. 质量：时间口径、部分收货处理、缺失数据。
7. 建议。

## 出库履约报告

1. 摘要：订单量、满足率、准时发运率。
2. KPI：订单满足率、缺货率、准时发运率、拣货准确率、履约周期。
3. 趋势：按日/周看订单量与履约指标。
4. 结构：按客户、仓库、订单类型、承运商拆解。
5. 异常：缺货订单、延迟发运、拣货差异、取消/退货。
6. 质量：承诺时间口径、拆单/并单处理、缺失数据。
7. 建议。

## 作业效率报告

1. 摘要：作业量、人效、峰值压力。
2. KPI：人均作业量、工时效率、环节耗时、库位利用率。
3. 趋势：按日/小时看作业量与效率。
4. 结构：按仓库、作业类型、班组拆解。
5. 异常：峰值拥堵、加班、环节瓶颈。
6. 质量：人数/工时口径、外包与临时工处理。
7. 建议。
