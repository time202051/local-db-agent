# 图表选型对照

| 数据形态 | 推荐图表 | 说明 |
|---|---|---|
| 时间序列趋势 | 折线图 | 周期多时用多条线；避免用柱状图堆叠时间点 |
| 类别对比 | 条形图（横向） | 类别名长时用横向；排序后更易读 |
| 构成占比 | 堆叠条形图 / 饼图 | 饼图类别不超过 6 个；跨时间构成用堆叠条形 |
| 时间 × 类别构成 | 堆叠面积图 / 堆叠条形 | 关注总量与结构变化时使用 |
| 分布 | 直方图 / 箱线图 | 分桶区间要写清；异常值单独标注 |
| 时间 × 维度热力 | 热力图 | 适合小时 × 星期、库区 × 品类 |
| 相关性 | 散点图 | 必须说明相关不等于因果 |
| 排名明细 | 表格 + 数据条 | 明细最多 10 行，超出给 Top N |
| 目标完成 | 柱线组合 / 进度条 | 双轴需标清单位和目标线 |
| 单值 KPI | 指标卡 | 带对比值和变化率，避免只放一个数 |

## 使用约束

- 同一报告保持 2~3 种图表类型，避免视觉噪音。
- 折线图时间轴必须按时间排序，缺失周期不要直接连线。
- 饼图/占比图所有分类合计应为 100%，并注明“其他”。
- 双轴图只用于量纲不同但相关的两条序列，左右轴都要写单位。
- 颜色语义全篇一致：例如红色固定表示异常/下降，不要同一颜色表达相反含义。
- 图表标题写“指标 + 维度 + 周期”，不要只写“趋势图”。
