# WMS 库存指标定义

## 基础指标

| 指标 | 公式 | 口径要点 | 推荐图表 |
|---|---|---|---|
| 库存量 | SUM(可用库存数量) | 快照时点、状态范围、单位 | KPI 卡 + 趋势线 |
| 库存金额 | SUM(数量 × 单位成本) | 成本口径、税率、币种 | KPI 卡 + 趋势线 |
| 库存周转次数 | 期间出库量 / 平均库存 | 分子分母同周期、同单位 | 趋势线 / 对比条形 |
| 库存周转天数 | 期间天数 / 周转次数 | 期间天数与出库量一致 | KPI 卡 + 趋势线 |
| 呆滞库存量 | 无出库天数 ≥ N 的库存 | N 需业务确认 | 条形图 + 明细表 |
| 呆滞库存金额 | 呆滞数量 × 单位成本 | 与库存金额同口径 | KPI 卡 + 结构图 |
| 库位利用率 | 占用库位数 / 可用库位数 | 占用定义、是否按容量 | 热力图 / 条形图 |
| 库存准确率 | 1 - 差异数量 / 系统数量 | 按 SKU + 库位 + 批次对齐 | KPI 卡 + 趋势线 |
| 账实差异率 | 差异数量绝对值 / 系统数量 | 盘点范围、时点 | 条形图 + 明细表 |

## 库龄

- 库龄 = 分析时点 - 入库日期（或批次日期，按客户口径）；
- 分桶建议：0~30、31~60、61~90、91~180、180+ 天；
- 同一 SKU 多批次时按批次分别计算，不要用最早入库日期代表全部；
- 输出：库龄分布（数量/金额）+ 180 天以上明细。

## 周转

- 平均库存三种口径，按数据可用性选择并注明：
  1. 每日快照均值（最准）；
  2. 期初 + 期末 / 2（近似）；
  3. 月末快照均值（多月时）。
- 出库量口径：出库单确认量、发运量还是拣货量，必须与业务确认；
- 周转天数 = 期间天数 / 周转次数，不要再用 365 / 周转次数 混用。

## ABC

- 按出库金额或出库量降序排列；
- 累计占比：A ≤ 70%，B 70%~90%，C > 90%；
- 若客户有既定阈值，以客户口径为准；
- 输出：A/B/C 的 SKU 数、库存金额、出库金额、占比。

## 数据质量检查

- 快照表每个时点是否唯一：同一 SKU + 库位 + 批次 + 状态是否重复；
- 快照日期是否连续，是否有缺失日期；
- 状态码是否都在映射表内，未知状态单独列出；
- 数量是否出现负数，负库存单独统计；
- 单位换算字段是否一致；
- 库存金额是否有空成本，空成本占比多少。
